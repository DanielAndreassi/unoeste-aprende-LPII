# Escopo (MVP)

Referência visual: telas do Aprender original (home "Minhas Disciplinas" + calendário; página da disciplina com menu lateral).

## Telas
- Login / Esqueci a senha / Definir nova senha (também usada na primeira senha)
- Header: logo, sino de notificações, Meu perfil, Sair, botão VLibras
- Meu perfil: foto, nome, trocar senha
- Home: Minhas Disciplinas (por semestre, agrupadas por curso) + calendário/eventos da semana
- Disciplina:
  - Início
  - Conteúdo: Tópicos (recolhíveis e no menu lateral) → Seções → Materiais (arquivo/link/texto), check de concluído por aluno
  - Professores
  - Participantes
  - Calendário
  - Plano de Ensino
  - Notas
  - Assistente IA
- Admin: usuários, cursos, disciplinas, turmas, matrículas
