# ADR-0011: Fora do escopo do MVP

- Status: Aceita
- Data: 2026-11-05

## Decisão
Não entram no MVP:
- **Entrega de atividades** (upload do aluno + correção). "Atividade" existe só como Evento com início/fim. Só volta se sobrar tempo depois de 14/11, ligada a uma Avaliação.
- **Frequência/faltas.**
- **Papel de coordenador e Sala do Coordenador** (o admin cobre a gestão).
- **Recursos Globais** e **mensagens entre usuários** (o envelope do header).
- **Autocadastro.**
- **IA lendo o conteúdo de PDFs** (melhoria futura: extrair o texto no upload).

## Consequências
Escopo cabe em 11 dias. Os itens acima ficam como "trabalhos futuros" na apresentação.
