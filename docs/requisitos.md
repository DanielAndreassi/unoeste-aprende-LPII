# Requisitos do Projeto Prático (LP II — BSI Unoeste/FIPP)

## Tecnologias mínimas
JavaScript, padrão MVC, Node.js, Express.js, Middlewares, API RESTful, MongoDB, Vue.js.

## Funcionalidades obrigatórias
- [ ] Login / autenticação de usuário
- [ ] Redefinição de senha
- [ ] CRUD via API RESTful de recursos do tema (poucos recursos = desconto na nota)
- [ ] Funcionalidades específicas do tema
- [ ] Front-end 100% Vue.js
- [ ] Mecanismo de Inteligência Artificial
